      Over jou

      Hoe meer de coach weet, hoe beter het advies past. Alles blijft op je telefoon, behalve wat je Claude vraagt.

      Claude

      Maak er een op console.anthropic.com. De sleutel blijft op dit toestel en gaat alleen naar Anthropic. Zet een bestedingslimiet in je account.

      Strava en Garmin

      Een GitHub Action haalt je gegevens op en zet ze versleuteld klaar. De app ontsleutelt ze met deze sleutel; dezelfde sleutel staat als COACH_SYNC_KEY in GitHub.

      Op GitHub Pages vult de app dit zelf in; laat het dan leeg.

      Alleen nodig voor de knop Nu synchroniseren of een privérepository. Een fine-grained token voor alleen deze repository, met Actions: read and write en Contents: read.
